# Kanban — тестовое задание

Канбан-доска на **webpack + React + TypeScript** (Node.js 18.18.0).

## Запуск

```bash
nvm use            # Node 18.18.0 (см. .nvmrc)
npm install
npm run start      # дев-сервер на http://localhost:3000
npm run test       # unit-тесты (jest)
npm run build      # production-сборка в ./dist
```

## Реализовано

Обязательные требования:
- задачи из `src/data/tasks.json` рендерятся по колонкам `todo / in_progress / review / done`;
- сортировка по `startDay` по возрастанию;
- просроченные задачи (`endDay` раньше сегодняшней даты, кроме статуса `done`) обводятся красным;
- удаление задач (иконка появляется при наведении на карточку);
- минимальная ширина 768px (меньше — горизонтальный скролл), максимальная 1920px (дальше — отступы по бокам).

Дополнительные:
- редактирование задач (иконка карандаша в колонке To Do, как в макете; `Enter` — сохранить, `Esc` — отмена, даты проверяются на формат `dd.mm.yyyy`) и добавление новых («+ Добавить»);
- drag&drop карточек между колонками (нативный HTML5 Drag and Drop);
- состояние хранится в `localStorage` (ключ `kanban.tasks`); если ключа нет — берутся данные из JSON;
- поиск: по подстроке в описании (без учёта регистра) или по дате `dd.mm.yyyy` (совпадение с `startDay` или `endDay`);
- unit-тесты на функцию `isTaskOverdue` (`src/utils/overdue.test.ts`) — `npm run test`.
